# SG4 - Understanding Classes and Objects
## OPM: Original Pop Music
## This class shows different examples of OPM. It includes the music genre, date released, and total number of listeners.
## Properties
| Property | Data Type | Description |
|---|---|---|
| Genre | string | Genre of the singer |
| Artist | string | The artist's name |
| Date | integer | Date of debut |
| Listeners | integer | Total number of listeners |

## Methods
| Method | Description |
|---|---|
| Search() | Search for the artist |
| Create() | Create a playlist based on the music genre |
| Delete | Delete the playlist |

## Design Explanation
### Why did you choose this class?
      I chose this class because I am an OPM enthusiast.
### Which property is the most important? Why?
      The most important is the Artist property because there are many OPM artists. Narrowing it down based on their name makes it easier to look for them.
### Which method is the most useful? Why?
    The most useful method is the Search. It is easier to look for any OPM once you search for it.
